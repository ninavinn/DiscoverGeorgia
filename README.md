# 🇬🇪 აღმოაჩინე საქართველო

ტურისტული ვებსაიტი, რომელიც წარმოადგენს საქართველოს მთავარ რეგიონებს, კულტურას და სამზარეულოს. პროექტი შესრულებულია **Skillwill**-ის პრაქტიკული დავალების ფარგლებში.

**ტექნოლოგიები:** HTML5 · CSS3 (Flexbox, Grid) · Vanilla JavaScript · Git/GitHub

---

## 1. პროექტის მიზანი

შევქმნათ სწრაფი, ხელმისაწვდომი და რესპონსიული ერთგვერდიანი საიტი, რომელიც მომხმარებელს აძლევს საქართველოს შესახებ საწყის ინფორმაციას და საშუალებას აძლევს, გამოგზავნოს ტურის მოთხოვნა.

**სამიზნე აუდიტორია:** უცხოელი და ადგილობრივი ტურისტები, რომლებიც მოგზაურობას გეგმავენ.

## 5. ვებგვერდის არქიტექტურა და მარკირება

```
discover-georgia/
├── index.html        # ერთგვერდიანი საიტი, სემანტიკური მარკირება
├── css/
│   └── style.css     # ცვლადები, განლაგება, თემები, რესპონსივობა
├── js/
│   └── main.js       # მოდულური ფუნქციები
└── README.md
```

**HTML5 სემანტიკა:** `header`, `nav`, `main`, `section`, `article`, `aside`, `figure/figcaption`, `footer`, `dl` სწრაფი ინფორმაციისთვის, `form` + `label`.

**ხელმისაწვდომობა:** `lang="ka"`, skip-link, `aria-label`, `aria-expanded`, `role="alert"` შეცდომებზე, ფოკუსის ხილვადი სტილი, `prefers-reduced-motion`-ის მხარდაჭერა.

**სექციები:** Hero → შესახებ → რეგიონები (სლაიდერი) → გალერეა (ფილტრით) → ციფრები → კონტაქტის ფორმა → ფუტერი.

## 6. ვიზუალური სტილი და რესპონსივობა

- **CSS ცვლადები** (`:root`) ერთი ადგილიდან მართავს ფერებს და ბნელ თემასაც
- **Grid:** "შესახებ" სექცია, გალერეის ბარათები (`auto-fill, minmax`), კონტაქტის განლაგება
- **Flexbox:** ჰედერი, ფილტრის ღილაკები, სტატისტიკა, ფორმა
- **Breakpoints:** `860px` (პლანშეტი: მენიუ გადაიქცევა ჰამბურგერად, ორი სვეტი ერთად), `480px` (მობილური)
- ეფექტები: sticky ჰედერი blur-ით, hover ანიმაციები, scroll reveal, hero-ს ანიმაცია

| მოწყობილობა | სიგანე | შედეგი |
|-------------|--------|--------|
| მობილური | < 480px | ერთი სვეტი, ჰამბურგერ მენიუ |
| პლანშეტი | 480–860px | ერთი/ორი სვეტი, ჰამბურგერ მენიუ |
| დესკტოპი | > 860px | სრული ნავიგაცია, მრავალსვეტიანი განლაგება |

## 9. ოპტიმიზაცია და პრობლემების გადაჭრა

**განხორციელებული ოპტიმიზაცია:**
- გარე ბიბლიოთეკების გარეშე, მხოლოდ სუფთა JS და CSS (მცირე წონა, ნაკლები მოთხოვნა)
- ფოტოების ნაცვლად CSS გრადიენტები და ემოჯი, ანუ ნულოვანი სურათის წონა
- `<script defer>`, რათა JS არ ბლოკავდეს გვერდის ჩვენებას
- Google Fonts-ზე `preconnect` და `display=swap`
- `IntersectionObserver` scroll-ის event listener-ის ნაცვლად (ნაკლები დატვირთვა)
- `requestAnimationFrame` და `passive` listener-ები სქროლზე
- ერთი `DOMContentLoaded` ინიციალიზაცია, მოდულური ფუნქციები
- `prefers-reduced-motion`-ის მხარდაჭერა

**პრობლემები და გადაწყვეტა:**

| პრობლემა | გადაწყვეტა |
|----------|-----------|
| localStorage ზოგ რეჟიმში მიუწვდომელია | `try/catch` შეფუთვა (`safeStorage`) |
| ფიქსირებული ჰედერი ფარავს სექციის სათაურს ანკორზე გადასვლისას | `scroll-padding-top` |
| სლაიდერი აგრძელებდა ბრუნვას მომხმარებლის ჩარევის დროს | ტაიმერის გადატვირთვა ყოველი ხელით გადართვისას |
| მობილურზე სლაიდერის დაბალი გამოსაყენებლობა | swipe მხარდაჭერა და aspect-ratio ცვლილება |
